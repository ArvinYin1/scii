## 关于脚本

这里的 `.py` 是当时实际跑过的测量脚本，保留下来作为方法证据。它们依赖一些**没有包含在本仓库中**的中间产物：

| 依赖 | 说明 |
|---|---|
| `analysis/full/` | 从参考视频解码出的 452 帧 PNG |
| `analysis/all/` | 同一视频按 6fps 抽样的帧 |
| `analysis/bg_median.npy` | 全部帧的中值背景（用于剔除鱼层、只留纸面与网格） |

这些全部是从第三方视频派生的素材，不随仓库分发。要复现的话，需要自备参考视频并自行抽帧，
再把脚本里的路径指过去——脚本本身没有写死任何非公开数据。

典型用途：

| 脚本 | 量的是什么 |
|---|---|
| `gridprecise.py` / `gridlines2.py` | 网格间距与相位（自相关 + 逐线定位） |
| `overlay2.py` | 把推测的网格叠回原图，肉眼验证是否对齐 |
| `ascii2.py` / `ascii_dump.py` | 按格导出字符画，看鱼体轮廓 |
| `rot_test.py` | 鱼体主轴角度分布（判断是精灵图还是任意朝向） |
| `field_test.py` / `interior_test.py` | 鱼身内部的明度是否空间连续（判断色是采样还是抖动） |
| `colors2.py` / `colors3.py` / `colors4.py` | 色族质心、格线色、文字色 |
| `measure.py` | 纸面亮度、网格间距的初测 |

## 结论摘要

一句话：**它不是「鱼形的图片在动」，而是一张固定的方格纸 + 一片字符场 + 若干鱼形遮罩在上面漂移。**

关键实测值（详见 `ANALYSIS.md`）：

- 纸面 `#FAFAF8`，网格 **19.5px** 均匀，格线仅比纸面深 4.8%
- 字格 = 一格 = 19.5px，一字一格，填色块贴满整格
- 鱼体约 **1 格/秒** 前进（≈20px/s），横穿画面约 50 秒
- 鱼身内部是**平滑色调场**，不是逐格随机抖动（相邻色差仅为独立预测值的 51%）
- **没有**径向白色光晕，**没有**位置相关的景深模糊；深度靠不透明度 + 尺寸
- 朝向往意分布（仅 39% 落在水平/垂直 12° 内），但**字符永远正立**在格纸坐标系里
